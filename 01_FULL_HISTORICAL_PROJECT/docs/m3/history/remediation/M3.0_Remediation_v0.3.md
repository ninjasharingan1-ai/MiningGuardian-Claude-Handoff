# M3.0 Remediation v0.3

Authorized after `M3.0 Architecture Review #2 — Read Only v0.2`.

## Closed Review #2 HIGH findings

1. Final M3.0 Gate now requires actual blocker closure and Final Acceptance/Baseline before M3.1.
2. Top-level architecture flow corrected so RewardTargetAuthority/Controller feeds DecisionContext/Decision Evaluation upstream of the M2 Decision Engine.
3. `RewardTargetPolicy` synonym removed; canonical governance component is `RewardTargetAuthority`. Frozen M2 `Policy` keeps admissibility semantics.
4. `MAXIMIZE` removed from RewardTarget objective types. RewardTarget supports `MINIMUM` and `BAND`; `MAXIMIZE` remains a strategic optimization objective.

## Closed Review #2 MEDIUM findings

5. Target lifecycle/state vocabulary synchronized.
6. Realized reward evidence no longer uses ambiguous ADR-0006 `ActionCost`; realized cost components are named explicitly.
7. Logical `M3 Runtime Evidence Persistence` ownership added, separate from frozen M2 decision persistence.
8. `ACTION_ATTRIBUTED` Outcomes now require an explicit auditable baseline/reference basis before Learning/Promotion.

## Scope

This pass is semantic/architectural only. It does not select storage technology, control algorithms, ML models, or live execution mechanisms.

A narrow read-only Architecture Review #3 is still required before final freeze.
