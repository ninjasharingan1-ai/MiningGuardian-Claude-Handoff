# M3.0 Remediation v0.2

This remediation is authorized after `M3.0 Architecture Review - Read Only`.

## Closed first-pass blockers

1. Target Authority separated from Reward Target Controller.
2. RewardContract added; ADR-0006 Risk/ActionCost/Uncertainty double-counting prohibited.
3. Outcome generalized to support PERFORMANCE_WINDOW without Execution and ACTION_ATTRIBUTED outcomes.
4. RewardEvaluationWindow / Pool Time Block added as a first-class contract.
5. Economic / Blockchain Intelligence moved before Reward Target shadow evaluation.
6. ExecutionAuthorization separated from ExecutionRecord; RollbackRecord separated.
7. Post-decision gate renamed/redefined as Execution Safety; M2 Policy remains candidate admissibility owner.
8. Learning Promotion Gate added: LearningArtifact → UpdateProposal → Verification → PromotionDecision → Active Version.

## Scope

The remediation intentionally does not claim final M3.0 acceptance. A second read-only Architecture Review is still required.
