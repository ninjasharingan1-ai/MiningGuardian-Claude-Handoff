## 6. Closed S2 Guarantees

The accepted evidence establishes only the following guarantees:

- UTF-8 SQLite compatibility precondition (BEGIN, then `PRAGMA main.encoding`, exact UTF-8 comparison, typed failure otherwise)
- fail-closed handling of UTF-16LE/UTF-16BE and unknown/missing encoding metadata
- canonical UTF-8 byte accounting via SQLite `length(CAST(payload_json AS BLOB))` and Python UTF-8 encoded lengths
- exact scan/decode boundary behavior (one-under refusal, exact/plus-one admission)
- cumulative Unicode byte accounting that cannot be bypassed by matching or nonmatching oversized records
- trusted application-supplied resource ceilings enforced before database access
- authenticated cursor integrity (HMAC-SHA256, request binding, watermark binding, positional coherence)
- deterministic pagination with no gaps or duplicates
- `COMPLETE` only on terminal completion; intermediate pages report `HAS_MORE`
- read-only evidence-query behavior over frozen M3.1 persistence
- bounded predecessor retrieval
- fail-closed corruption, schema, identity, and database-read handling
