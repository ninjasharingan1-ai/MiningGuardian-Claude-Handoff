# M3.2 S4A R2-B — Exclusion-Reason Authority Clarification

## Status

`R2B_EXCLUSION_REASON_AUTHORITY_CLARIFIED`

ACCEPTED NORMATIVE CLARIFICATION.

This clarification resolves only the confirmed R2-B accounting gap for
`MethodEvidenceUse.reason` when the authoritative result is
`NO_SINGLE_COMPARABLE_ANALYTICAL_SET`.

## Accepted closed reason

The following is the sole closed R2 method-layer exception to the rule that
`EXCLUDED` reasons originate from accepted upstream artifacts:

`method:no_single_comparable_analytical_set`

This reason is derived from the R2 support-binding outcome itself.

It is not:

- an S3 disposition;
- a conflict reason;
- a `not_compared` reason;
- evidence of agreement;
- evidence of disagreement;
- authorization to merge streams;
- authorization to select a provider or winner.

## Exact authorization

R2 MAY emit:

`MethodEvidenceUse(role="EXCLUDED", reason="method:no_single_comparable_analytical_set")`

only when all of the following hold:

1. the method uses the current-support view;
2. the observation is otherwise eligible;
3. multiple eligible support streams remain;
4. no full-population authoritative S3 agreement authorizes one analytical set;
5. no authoritative unresolved full-population conflict supplies a conflict-derived reason;
6. the result is exactly `NO_SINGLE_COMPARABLE_ANALYTICAL_SET`;
7. no more specific accepted artifact-derived exclusion reason applies.

More specific artifact-derived reasons always take precedence.

## Preserved semantics

- unresolved conflict → `UNRESOLVED_CONFLICT`;
- multiple valid support possibilities without one authorized analytical set
  → `NO_SINGLE_COMPARABLE_ANALYTICAL_SET`;
- one full authoritative S3 agreement → bind that set;
- separate partial agreement groups → never merge;
- `not_compared` → never grants cross-stream support;
- no provider ranking or hidden winner is authorized.

## Namespace decision

The provisional reason:

`comparison:no_authorized_cross_stream_join`

is rejected.

The accepted replacement is:

`method:no_single_comparable_analytical_set`

The `method:` namespace is required because the exclusion comes from R2
support-binding authority, including cases where no S3 comparison artifact exists.

## Scope

This clarification applies only to:

- M3.2 S4-A;
- R2-B;
- current multi-stream support binding;
- `MethodEvidenceUse.reason`;
- `NO_SINGLE_COMPARABLE_ANALYTICAL_SET`.

It does not authorize arithmetic, R3 execution, conversion, historical continuity
semantics, assessment, assembly, persistence, production, provider ranking,
conflict resolution policy, or missing-fraction opportunity semantics.

## Acceptance

Authority decision:

`R2B_EXCLUSION_REASON_AUTHORITY_CLARIFIED`

The clarification supersedes only the conflicting part of the earlier R2
evidence-use rule that required every `EXCLUDED` reason to originate from an
upstream accepted artifact.

All other R2 authority remains unchanged.
